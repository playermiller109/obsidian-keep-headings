- Navigation-triggered renaming: See [t86850#9](https://forum.obsidian.md/t/mini-plugin-update-internal-links-when-renaming-a-heading/86850/9) for a version, while some users reported certain problems in [t75847#7](https://forum.obsidian.md/t/always-run-rename-this-heading-command-when-a-heading-is-clicked/75847/7), for your reference.

## 20241017

Some behaviors of the Core plugin Page preview are native to Obsidian and not caused by this plugin. In any page preview, you can right-click to open the context menu and click to select any item; the preview popover will close immediately.

To bypass this, use a preview editing view that overrides the native one, just as you did when the Page preview didn’t support it.
